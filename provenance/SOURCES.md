## First public release record

- `https://satoshi.nakamotoinstitute.org/emails/cryptography/16/`

The January 8, 2009 announcement identifies `bitcoin-0.1.0.rar`, says the open-source C++ code is included, and instructs users to unpack and run `BITCOIN.EXE`.

## Provenance caution

The January archives have a documented recovery path through Hal Finney in 2012. The November archive is a later-publicly-preserved pre-release source witness. Neither establishes that no private drafts or additional files ever existed.
